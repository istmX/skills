# @istmx/skills | Context-as-a-Service (CaaS) for AI Coding Agents

**The Ultimate AI Orchestrator and Context Engine for Cursor, Windsurf, Claude Code, and Gemini.**

Are you tired of AI coding assistants hallucinating tech stacks, generating generic UI slop, and losing project context? `@istmx/skills` is a revolutionary **Context-as-a-Service (CaaS)** framework that hijacks your AI agent's harness (like `.cursorrules`, `.cline`, or `GEMINI.md`) and injects an **Elite Orchestration Engine**. By enforcing strict system design and premium UI/UX rules, it forces your LLM to write modular, production-ready blueprints before it ever touches a line of code.

Whether you are building a scalable SaaS startup, an enterprise backend, or an Awwwards-winning frontend with GSAP animations, `@istmx/skills` guarantees deterministic, high-quality code generation.

## 🚀 Installation & Setup

Run the developer-tools CLI inside the root of your project:

```bash
npx @istmx/skills init
```

The CLI will automatically detect your AI IDE (Cursor, Windsurf, Roo Code, GitHub Copilot) and inject the master orchestrator, instantly upgrading your developer experience (DX) and productivity.

## 🧠 The Core Orchestrators (God Mode Skills)

When you run `init`, you can inject highly specialized orchestrators tailored to modern software engineering:

- **`/istm` (Universal NLP Router)**: The master brain for Generative AI. Type `/istm I need a new auth feature`, and it dynamically routes your prompt to the exact workflow tool required.
- **`/istm-architecture` (Fullstack System Design)**: Forces the AI to establish the 4 Pillars of Truth (`project-overview.md`, `architecture.md`, `design.md`, `agents.md`). Perfect for Next.js, React, TailwindCSS, Prisma, and Supabase stacks.
- **`/istm-awwward-designer` (Premium UI & Motion Engine)**: Builds Awwwards-winning marketing sites. Explicitly enforces **GSAP**, **Framer Motion**, **Lenis smooth scrolling**, WebGL, and strict typography scaling. Say goodbye to boring Bootstrap templates.
- **`/istm-system-design` (Backend API Architect)**: The backend brain. Generates strict database schemas, REST/GraphQL APIs, and ORM setups (PostgreSQL, MongoDB, Drizzle).

## 🛠️ AI Workflow Tools (Day-to-Day Execution)

Transform your prompt engineering into a deterministic workflow:

- **`/istm-craft`**: Give it a feature idea. It reads your `.istm-context/` knowledge base and writes a strict technical spec, preventing AI hallucinations.
- **`/istm-develop`**: The ultimate code-generator. It reads the specs from `/istm-craft` and autonomously writes clean code.
- **`/istm-debug`**: Hit a massive wall? This autonomous agent hunts down root causes and maintains an `error-memory.md` log, ensuring the AI never makes the same mistake twice.
- **`/istm-audit`**: Checks your codebase for tech debt, architectural drift, and enforces best practices.

## 📁 How It Works: The `.istm-context` Architecture

We believe in **Blueprint Centralization** and Retrieval-Augmented Generation (RAG) principles. 
When your AI runs an orchestrator, it generates a `.istm-context/` folder. This acts as the single source of truth for your app's architecture and design system. 

Every single time you ask your AI to build a new feature, it is forced to read `.istm-context/design.md` (to get the exact UI tokens, micro-interactions, and colors) and `.istm-context/architecture.md` (to verify the tech stack) before it outputs code.
